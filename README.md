# PulseLift — Workout Tracker

A 2-day full-body workout routine (Day A and Day B) as an installable web app.

- 3D anatomical models: drag to rotate 360°, hover or tap to highlight the target muscles
- Exercise library with form guides
- Weight and rep logging with workout history and total volume
- Rest timer with presets (compound, upper/lunges, long rest)
- Works offline and can be installed to the home screen (PWA)

Built with plain HTML, CSS and JavaScript. No libraries, no build step.

## Run

Open `index.html` in a browser, or serve the folder (needed for offline mode and install):

```bash
python -m http.server 8000
```

Then go to `http://localhost:8000`.
